# 5.3. Сигналы выводов

Эти сигналы соединяют контроллер с контактными площадками кристалла
через двунаправленные буферы. При интеграции нужно правильно
использовать выводы периферии, чтобы выполнить требования
интерфейса.

## Описание сигналов

| Имя | Тип | Тип вывода | Описание |
|-----|-----|------------|----------|
| `nGPEN[7:0]` | Выход | Вывод | Разрешение выходного буфера, активный низким уровнем |
| `GPOUT[7:0]` | Выход | Вывод | Данные для выходного буфера |
| `GPIN[7:0]` | Вход | Вывод | Данные, приходящие с вывода |

## `nGPEN`

Управляется регистром `GPIODIR` в программном режиме либо
вспомогательными сигналами в аппаратном режиме.

| Значение | Действие |
|----------|----------|
| 0 | Выходной буфер включён, вывод работает на выход |
| 1 | Выходной буфер выключен, вывод работает на вход |

Активный низкий уровень означает, что после сброса, когда
`GPIODIR = 0x00`, все выходные буферы выключены.

## `GPOUT`

Данные выходного буфера. Источник — `GPIODATA` в программном режиме
или `GPAFOUT` в аппаратном.

## `GPIN`

Данные с вывода. Значения читаются через APB в программном режиме;
в аппаратном режиме они также передаются на `GPAFIN`. Чтение через
APB доступно в обоих режимах.

## Схема подключения

```text
                  ┌─────────────┐
   nGPEN[7:0] ───▶│             │
   GPOUT[7:0] ───▶│   Буфер     │◀──▶  Контактная площадка
   GPIN[7:0]  ◀───│             │
                  └─────────────┘
```

## Режимы

| Режим | `nGPEN` | `GPOUT` | `GPIN` |
|-------|---------|---------|--------|
| Программный | из `GPIODIR` | из `GPIODATA` | в `GPIODATA` |
| Аппаратный | из `nGPAFEN` | из `GPAFOUT` | в `GPAFIN` и `GPIODATA` |

## Замечание

Электрические характеристики выводов — допустимые токи, подтяжки,
защита от электростатического разряда — задаются при интеграции
кристалла и в состав блока не входят.
