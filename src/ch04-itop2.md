# 4.3.5. GPIOITOP2

`GPIOITOP2` — регистр чтения внутрикристального выхода `GPIOINTR`.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x610` |
| Тип | RO |
| Ширина | 1 бит |
| Сброс | `0x0` |

## Битовые поля

| Биты | Имя | Описание |
|------|-----|----------|
| 7:1 | — | Зарезервировано, при чтении не определено |
| 0 | `GPIOINTR` | Значение объединённого выхода прерываний |

## Что показывает

Бит отражает состояние `GPIOINTR`. В тестовом режиме (`ITEN = 1`)
он равен логическому ИЛИ по всем битам `GPIOMIS`, установленным
через `GPIOITOP1`.

| `GPIOITOP1` | `GPIOITOP2[0]` |
|-------------|----------------|
| `0x00` | 0 |
| любое ненулевое значение | 1 |

## Почему отдельный регистр

`GPIOINTR` — выходной сигнал, только для чтения. Записать его
напрямую нельзя: значение задаётся через `GPIOMIS`. `GPIOITOP2`
даёт программе способ увидеть результат этого ИЛИ.

## Пример

```c
#define GPIO_ITOP1  (GPIO_BASE + 0x60C)
#define GPIO_ITOP2  (GPIO_BASE + 0x610)

*(volatile uint32_t *)(GPIO_BASE + 0x600) = 1;  /* ITEN = 1 */

*(volatile uint32_t *)GPIO_ITOP1 = 0x01;
if (!(*(volatile uint32_t *)GPIO_ITOP2 & 1))
    /* GPIOINTR не поднялся — ошибка */

*(volatile uint32_t *)GPIO_ITOP1 = 0x00;
if (*(volatile uint32_t *)GPIO_ITOP2 & 1)
    /* GPIOINTR остался высоким — ошибка */
```

## Замечание

Читать `GPIOITOP2` можно независимо от значения `ITEN`, но
осмысленным результат будет только в тестовом режиме, когда
источником `GPIOMIS` служит `GPIOITOP1`.
