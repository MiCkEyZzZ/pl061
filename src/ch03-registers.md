# 3.3. Описание регистров

В разделе описан каждый регистр: назначение, поля и правила
обращения. Тестовые регистры описаны отдельно в главе 4.

## Порядок изложения

| Раздел | Регистр |
|--------|---------|
| 3.3.1 | `GPIODATA` — данные |
| 3.3.2 | `GPIODIR` — направление |
| 3.3.3 | `GPIOIS` — чувствительность |
| 3.3.4 | `GPIOIBE` — оба фронта |
| 3.3.5 | `GPIOIEV` — событие |
| 3.3.6 | `GPIOIE` — маска |
| 3.3.7 | `GPIORIS` — сырой статус |
| 3.3.8 | `GPIOMIS` — маскированный статус |
| 3.3.9 | `GPIOIC` — сброс |
| 3.3.10 | `GPIOAFSEL` — режим |
| 3.3.11 | `GPIOPeriphID0-3` — идентификация периферии |
| 3.3.12 | `GPIOPCellID0-3` — идентификация PrimeCell |

## Общие свойства

- Каждый бит регистра соответствует одной линии `GPIO[n]`.
- После сброса все регистры равны нулю.
- Разрядность всех полей — 8 бит.
- Зарезервированные биты читаются как нули или не определены.

## Порядок настройки прерываний

```text
GPIOIS → GPIOIBE → GPIOIEV → выдержка → GPIOIC → GPIOIE
```

Соблюдение порядка исключает ложные срабатывания. Подробнее —
в разделе 2.3.2.
