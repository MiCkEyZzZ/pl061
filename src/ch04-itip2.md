# 4.3.3. GPIOITIP2

`GPIOITIP2` — регистр чтения и установки внутрикристального входа
`nGPAFEN[7:0]`.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x608` |
| Тип | RW |
| Ширина | 8 бит |
| Сброс | `0x00` |

## Битовые поля

| Биты | Имя | Описание |
|------|-----|----------|
| 7:0 | `nGPAFEN` | Значение, подаваемое на внутрикристальный вход |

## Активный уровень

`nGPAFEN` — сигнал разрешения, активный **низким** уровнем:

| Бит | Значение для линии |
|-----|--------------------|
| 0 | Выход разрешён (аппаратный режим, выход) |
| 1 | Выход запрещён (аппаратный режим, вход) |

Именно поэтому имя начинается с `n`.

## Запись и чтение

- Запись задаёт значение, выдаваемое на `nGPAFEN[7:0]` в тестовом
  режиме.
- Чтение возвращает значение на выходе тестового мультиплексора:
  из внешнего блока при `ITEN = 0` или из регистра при `ITEN = 1`.

## Пример

```c
#define GPIO_ITIP2  (GPIO_BASE + 0x608)

/* Все линии — выходы в аппаратном режиме */
*(volatile uint32_t *)GPIO_ITIP2 = 0x00;

/* Все линии — входы в аппаратном режиме */
*(volatile uint32_t *)GPIO_ITIP2 = 0xFF;
```

## Замечание

Неиспользуемые входы `nGPAFEN` в реальной системе должны быть
привязаны к высокому уровню. В тестовом режиме это требование
не действует: значение задаёт регистр.
