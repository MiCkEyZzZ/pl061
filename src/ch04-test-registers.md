# 4.3. Интеграционные тестовые регистры

Тестовые регистры отображены в память по фиксированным смещениям
от базового адреса контроллера.

## Карта тестовых регистров

| Смещение | Имя | Тип | Ширина | Сброс | Назначение |
|----------|-----|-----|--------|-------|------------|
| `+0x600` | `GPIOITCR` | RW | 1 | `0x0` | Управление тестом |
| `+0x604` | `GPIOITIP1` | RW | 8 | `0x00` | Чтение/установка входа `GPAFOUT` |
| `+0x608` | `GPIOITIP2` | RW | 8 | `0x00` | Чтение/установка входа `nGPAFEN` |
| `+0x60C` | `GPIOITOP1` | WO | 8 | `0x00` | Установка выхода `GPIOMIS` |
| `+0x610` | `GPIOITOP2` | RO | 1 | `0x0` | Чтение выхода `GPIOINTR` |
| `+0x614` | `GPIOITOP3` | RW | 8 | `0x00` | Чтение/установка выхода `GPAFIN` |

## Особенности

**`GPIOITOP1`.** Только для записи. Прочитать записанное значение
можно в `GPIOMIS`, если установлен бит `ITEN`.

**`GPIOITOP2`.** Один бит. Отражает состояние `GPIOINTR`, то есть
результат логического ИЛИ по всем битам `GPIOMIS`, установленным
при `GPIOITCR = 1`.

**`GPIOITOP3`.** Записанное значение выдаётся на `GPAFIN[7:0]`;
читается значение на выходе тестового мультиплексора.

## Пример включения тестового режима

```c
#define GPIO_ITCR   (GPIO_BASE + 0x600)
#define GPIO_ITIP1  (GPIO_BASE + 0x604)
#define GPIO_ITIP2  (GPIO_BASE + 0x608)
#define GPIO_ITOP1  (GPIO_BASE + 0x60C)
#define GPIO_ITOP2  (GPIO_BASE + 0x610)
#define GPIO_ITOP3  (GPIO_BASE + 0x614)

/* Войти в интеграционный тестовый режим */
*(volatile uint32_t *)GPIO_ITCR = 1;

/* ... проверки ... */

/* Вернуться в обычный режим */
*(volatile uint32_t *)GPIO_ITCR = 0;
```

## Замечание

После выхода из тестового режима регистры данных и прерываний
возвращаются к обычному поведению. Состояние, накопленное
в тестовом режиме, следует сбросить перед началом нормальной
работы.
