# 2.1.2. Регистр данных

`GPIODATA` — регистр данных. Через него читается состояние выводов
и задаются значения выходов.

## Адресация

Регистр занимает не один адрес, а 256 последовательных адресов
от `base + 0x000` до `base + 0x3FC`. Младшие биты адреса
`PADDR[9:2]` образуют маску.

| Операция | Действие маски |
|----------|----------------|
| Запись | Бит изменяется, только если соответствующий бит маски равен 1 |
| Чтение | Бит возвращается, только если соответствующий бит маски равен 1; иначе читается 0 |

## Пример записи

```text
Адрес = GPIODATA + 0x098
PADDR[9:2] = 0b0000100110
Маска: биты 5, 2, 1
Данные = 0xFB
Результат: бит 5 = 1, бит 2 = 0, бит 1 = 1,
           остальные биты не изменяются
```

## Пример чтения

```text
Адрес = GPIODATA + 0x0C4
PADDR[9:2] = 0b0000110001
Маска: биты 5, 4, 0
Результат: возвращаются только биты 5, 4, 0,
           биты 7, 6, 3, 2, 1 читаются как 0
```

## Что возвращает чтение

- Для линии-выхода — последнее записанное значение.
- Для линии-входа — текущий уровень на выводе.

Это позволяет одним обращением прочитать состояние всех линий.
Полный доступ без маски даёт адрес `base + 0x3FC`.

## Замечание о задержке

Данные на входах считаются потенциально асинхронными по отношению
к `PCLK`. Перед чтением `GPIN` через `GPIODATA` должно пройти
не менее двух передних фронтов `PCLK`.
