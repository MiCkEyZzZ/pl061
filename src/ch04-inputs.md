# 4.4. Тестирование входов

Входы делятся на две группы, и для каждой применяется свой способ
проверки.

| Группа | Сигналы | Способ |
|--------|---------|--------|
| Внутрикристальные | `GPAFOUT[7:0]`, `nGPAFEN[7:0]` | Запись через `GPIOITIP1`/`GPIOITIP2` и чтение обратно |
| Первичные | `GPIN[7:0]` | Шлейф через trickbox и чтение через `GPIODATA` |

## Общая идея

Вход проверяется так: на него подаётся известное значение, а затем
программа читает то, что дошло до внутренней точки наблюдения.
Если прочитанное совпало с поданным, соединение и логика исправны.

## Что проверяется

- **Соединение** сигнала с источником.
- **Отсутствие залипания** на нуле или единице.
- **Правильность разводки** отдельных линий, а не только шины целиком.

## Последовательность

```text
1. Установить ITEN = 1.
2. Подать шаблон на тестовый регистр входа.
3. Прочитать значение из регистра или из GPIODATA.
4. Сравнить с ожидаемым.
5. Повторить для всех битов.
6. Установить ITEN = 0.
```

## Замечание о задержке

Первичные входы `GPIN[7:0]` потенциально асинхронны по отношению
к `PCLK`. Поэтому между подачей значения на вывод и чтением
`GPIODATA` должно пройти не менее двух передних фронтов `PCLK`.
