# 1.1.1. Особенности

## Линии ввода-вывода

- **Восемь независимых линий** `GPIO[7:0]`.
- Каждая линия независимо настраивается на вход или выход через
  `GPIODIR`.
- После сброса все линии работают как входы.
- Чтение `GPIODATA` возвращает состояние выводов независимо от
  выбранного направления.

## Доступ к данным

- **Маскированная адресация.** Регистр данных занимает 256 адресов;
  биты адреса `PADDR[9:2]` выбирают, какие биты изменять или читать.
- Это позволяет одному драйверу менять свои линии, не затрагивая
  остальные, без чтения-модификации-записи.
- Запись воздействует только на линии, настроенные как выходы.

## Прерывания

- Обнаружение **уровня** или **фронта** — выбор через `GPIOIS`.
- Для фронта доступны **оба направления** (`GPIOIBE`) либо одно,
  заданное `GPIOIEV`.
- Индивидуальное маскирование каждой линии через `GPIOIE`.
- Сырой (`GPIORIS`) и маскированный (`GPIOMIS`) статус.
- Сброс флагов записью единицы в `GPIOIC`.
- Общий выход `GPIOINTR` и индивидуальные прерывания.

## Режимы управления

- **Программный режим:** линия управляется регистрами.
- **Аппаратный режим:** линия управляется внешним блоком через
  `GPIOAFSEL`; регистры данных игнорируются.
- В аппаратном режиме значения линий всё равно доступны для чтения
  через `GPIODATA`.

## Идентификация

- Регистры `GPIOPeriphID0-3` дают код компонента `0x061`.
- Регистры `GPIOPCellID0-3` дают идентификатор PrimeCell
  `0xB105F00D`.

## Тестирование

- Встроенная логика интеграционного теста.
- Отдельные регистры управления тестом и доступа к входам-выходам.
- Поддержка scan-тестирования.

## Шина

- Интерфейс AMBA APB, ведомое устройство.
- 32-битные обращения, 8 значащих бит данных.
- Отдельный сброс интерфейса `PRESETn`.
