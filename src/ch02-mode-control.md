# 2.2.3. Управление режимом

Линией можно управлять программно через APB или аппаратно через
интерфейс аппаратного управления. Режим каждой линии выбирается
битом регистра `GPIOAFSEL`.

## Программный режим

При `GPIOAFSEL[n] = 0`:

- направление задаёт `GPIODIR[n]`;
- запись данных идёт через `GPIODATA`;
- чтение состояния доступно через `GPIODATA`.

Это режим по умолчанию после сброса.

## Аппаратный режим

При `GPIOAFSEL[n] = 1`:

- направление задаётся сигналом `nGPAFEN[n]`;
- выходные данные берутся из `GPAFOUT[n]`;
- входные данные выдаются на `GPAFIN[n]`;
- состояние линии по-прежнему можно прочитать через `GPIODATA`.

Регистры `GPIODIR` и `GPIODATA` для этой линии не действуют.

## Мультиплексор

```text
GPIODIR ─────┐
             ├──▶ nGPEN
nGPAFEN ─────┘

GPIODATA ────┐
             ├──▶ GPOUT
GPAFOUT ─────┘

GPIN ────────┼──▶ GPIODATA (чтение)
             └──▶ GPAFIN
```

## Когда нужен аппаратный режим

- Линия управляется другим периферийным блоком.
- Нужна работа без участия процессора.
- Требуется переключение функций вывода в зависимости от
  конфигурации системы.

## Замечание

В аппаратном режиме сигнал `GPAFIN` для входов и `GPAFOUT` для
выходов должны быть подключены или зафиксированы. Неиспользуемые
входы `nGPAFEN` следует привязать к высокому уровню.
