# 5.1. Сигналы AMBA APB

Контроллер подключён к шине AMBA APB как ведомое устройство.
Сигналы APB имеют префикс `P` и активны **высоким** уровнем;
активные низким уровнем сигналы содержат строчную `n`.

## Описание сигналов

| Имя | Тип | Источник / приёмник | Описание |
|-----|-----|---------------------|----------|
| `PRESETn` | Вход | Контроллер сброса | Сброс шины, активный низким уровнем |
| `PADDR[11:2]` | Вход | APB | Часть адресной шины |
| `PCLK` | Вход | APB | Тактовый сигнал, по которому выполняются все передачи |
| `PENABLE` | Вход | APB | Разрешение передачи: высокий уровень в течение одного такта `PCLK` |
| `PRDATA[7:0]` | Выход | APB | Часть однонаправленной шины данных чтения |
| `PSEL` | Вход | APB | Выбор устройства от декодера |
| `PWDATA[7:0]` | Вход | APB | Часть однонаправленной шины данных записи |
| `PWRITE` | Вход | APB | Направление передачи: 1 — запись, 0 — чтение |

## Как выполняется передача

```text
1. Ведущее устройство выставляет PSEL = 1 и адрес PADDR.
2. Выставляется PWRITE: 1 для записи, 0 для чтения.
3. На следующем такте PENABLE = 1 — передача завершается.
4. При записи данные берутся с PWDATA, при чтении
   выдаются на PRDATA.
```

## Особенности

**Адрес.** Используются разряды `PADDR[11:2]` — двенадцать бит
позволяют адресовать 4 КБ, а младшие два бита отброшены, так как
обращения 32-битные.

**Данные.** Разрядность выбрана 8 бит, поскольку все регистры
контроллера занимают младший байт слова.

**Сброс.** `PRESETn` обнуляет регистры и переводит линии в режим
входа. Он не влияет на состояние внешних сигналов, подключённых
к выводам.

## Замечание о `PSEL`

`PSEL` формируется декодером шины и означает, что выбрано именно
это устройство. При `PSEL = 0` контроллер не реагирует
на изменения остальных сигналов.
