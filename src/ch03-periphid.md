# 3.3.11. Идентификация GPIOPeriphID0-3

Четыре 8-битных регистра в диапазоне `0xFE0`–`0xFEC` содержат
постоянный идентификатор периферии.

## Расположение

| Регистр | Смещение | Значение |
|---------|----------|----------|
| `GPIOPeriphID0` | `0xFE0` | `0x61` |
| `GPIOPeriphID1` | `0xFE4` | `0x10` |
| `GPIOPeriphID2` | `0xFE8` | `0x04` |
| `GPIOPeriphID3` | `0xFEC` | `0x00` |

Составное 32-битное слово: `0x00041061`.

## Поля

| Поле | Биты слова | Значение |
|------|------------|----------|
| `PartNumber[11:0]` | `[11:0]` | `0x061` |
| `Designer ID[19:12]` | `[19:12]` | `0x41` (ASCII `A`, ARM) |
| `Revision[23:20]` | `[23:20]` | Номер ревизии |
| `Configuration[31:24]` | `[31:24]` | `0x00` |

## Разбивка по регистрам

| Регистр | Поле | Значение |
|---------|------|----------|
| `GPIOPeriphID0` | `PartNumber0` | `0x61` |
| `GPIOPeriphID1[7:4]` | `Designer0` | `0x1` |
| `GPIOPeriphID1[3:0]` | `PartNumber1` | `0x0` |
| `GPIOPeriphID2[7:4]` | `Revision` | `0x0` |
| `GPIOPeriphID2[3:0]` | `Designer1` | `0x4` |
| `GPIOPeriphID3` | `Configuration` | `0x00` |

## Пример проверки

```c
static int pl061_present(void)
{
    uint32_t id = 0;

    for (int i = 0; i < 4; i++)
        id |= (*(volatile uint32_t *)(GPIO_BASE + 0xFE0 + 4 * i) & 0xFF)
              << (8 * i);

    return id == 0x00041061;
}
```

## Замечание

Регистры только для чтения. Обращения должны быть 32-битными;
при сравнении маскируется младший байт, так как старшие биты
слова не определены.
