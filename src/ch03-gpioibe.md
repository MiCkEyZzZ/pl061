# 3.3.4. Оба фронта GPIOIBE

`GPIOIBE` определяет, реагирует ли линия на оба фронта или только
на один, выбранный в `GPIOIEV`.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x408` |
| Тип | RW |
| Ширина | 8 бит |
| Сброс | `0x00` |

## Битовые поля

| Бит | Значение |
|-----|----------|
| 0 | Один фронт, направление задаёт `GPIOIEV` |
| 1 | Оба фронта |

## Область действия

Регистр действует только для линий, у которых в `GPIOIS` выбран
фронт. Для линий с обнаружением уровня бит `GPIOIBE` не имеет
значения.

## Пример

```c
/* Линия 2 реагирует на оба фронта */
*(volatile uint32_t *)(GPIO_BASE + 0x408) = 1u << 2;
```

## Применение

Обнаружение обоих фронтов удобно для:

- счётчиков импульсов;
- кнопок, которые могут замыкаться и размыкаться;
- сигналов, у которых важен сам факт изменения.

## Замечание

При обоих фронтах бит `GPIOIEV` для этой линии игнорируется.
Сброс флага всё равно выполняется через `GPIOIC`.
