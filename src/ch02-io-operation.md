# 2.3.3. Работа линий ввода-вывода

Контроллер содержит восемь программируемых линий. В программном
режиме данные и управление берутся из регистра данных и регистра
направления.

## Чтение

При чтении регистр данных содержит текущее состояние выводов
независимо от того, настроены они как входы или как выходы.
Для выхода возвращается последнее записанное значение.

## Запись

Запись в регистр данных воздействует только на линии, настроенные
как выходы. Линии-входы не изменяются.

## Маска адреса

Чтобы разные драйверы могли менять свои биты, не затрагивая чужие,
адресная шина используется как маска. Регистр данных занимает
256 адресов, маска — `PADDR[9:2]`.

**Запись.** Если бит адреса, связанный с битом данных, равен 1,
значение бита изменяется. Если 0 — бит остаётся прежним.

**Чтение.** Если бит адреса равен 1, соответствующий бит данных
читается. Если 0 — читается ноль, независимо от состояния линии.

## Пример записи

```text
GPIODATA + 0x098 = 0b000010011000
PADDR[9:2] = 0b0000100110
Записываем 0xFB:
  бит 5 → 1
  бит 2 → 0
  бит 1 → 1
  остальные не меняются
```

## Пример чтения

```text
GPIODATA + 0x0C4 = 0b000011000100
PADDR[9:2] = 0b0000110001
Возвращаются биты 5, 4, 0;
биты 7, 6, 3, 2, 1 читаются как 0.
```

## Направление

| `GPIODIR[n]` | Направление |
|--------------|-------------|
| 0 | Вход |
| 1 | Выход |

## Полный доступ

Адрес `GPIODATA + 0x3FC` соответствует маске `0xFF`: читаются
и записываются все восемь бит.
