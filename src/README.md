# ARM PrimeCell GPIO (PL061)

## Техническое руководство

PL061 — контроллер ввода-вывода общего назначения (GPIO) семейства
ARM PrimeCell. Он предоставляет восемь программируемых линий, которые
могут работать как входы или выходы, поддерживает маскируемые
прерывания по уровню и фронту, а также альтернативный аппаратный
режим управления.

Эта книга — русскоязычное описание устройства, составленное по структуре
официального руководства ARM **DDI 0190B** (ARM PrimeCell General Purpose
Input/Output (PL061) Technical Reference Manual). Она не является
официальным переводом ARM и не заменяет оригинальную документацию.

### Базовые сведения

| Параметр | Значение |
|----------|----------|
| Семейство | ARM PrimeCell |
| Шина | AMBA APB, ведомое устройство |
| Число линий | 8 |
| Разрядность регистров | 8 бит в 32-битных словах |
| Прерывания | По уровню и по фронту, маскируемые |
| Режимы | Программный и аппаратный |
| Область адресов | 4 КБ |

Смещения регистров указаны относительно базового адреса блока, который
назначается при интеграции контроллера в систему на кристалле.
