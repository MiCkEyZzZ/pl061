# 4.3.1. GPIOITCR

`GPIOITCR` — регистр управления интеграционным тестом. Он определяет,
работает контроллер в обычном режиме или в режиме теста.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x600` |
| Тип | RW |
| Ширина | 1 бит |
| Сброс | `0x0` |

## Битовые поля

| Биты | Имя | Описание |
|------|-----|----------|
| 7:1 | — | Зарезервировано, при чтении не определено |
| 0 | `ITEN` | Разрешение интеграционного теста |

## Значение ITEN

| `ITEN` | Режим |
|--------|-------|
| 0 | Обычная работа контроллера |
| 1 | Интеграционный тестовый режим |

## Что меняется при ITEN = 1

| Сигнал | Источник в тестовом режиме |
|--------|----------------------------|
| `GPAFOUT[7:0]` | `GPIOITIP1[7:0]` |
| `nGPAFEN[7:0]` | `GPIOITIP2[7:0]` |
| `GPIOMIS[7:0]` | `GPIOITOP1[7:0]` |
| `GPAFIN[7:0]` | `GPIOITOP3[7:0]` |

Обратные пути также переключаются: значения внутрикристальных
входов и выходов читаются через те же регистры, а не через
рабочую логику.

## Пример

```c
/* Включить тестовый режим */
*(volatile uint32_t *)(GPIO_BASE + 0x600) = 0x1;

/* ... */

/* Выключить */
*(volatile uint32_t *)(GPIO_BASE + 0x600) = 0x0;
```

## Замечание

Бит `ITEN` — единственный управляющий бит тестовой обвязки.
Все остальные тестовые регистры имеют смысл только при `ITEN = 1`.
