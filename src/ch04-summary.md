# 4.6. Итоги интеграционного тестирования

Таблица сводит стратегии проверки для всех выводов контроллера.

## Сводная таблица

| Сигнал | Тип | Приёмник / источник | Способ проверки |
|--------|-----|---------------------|-----------------|
| `PRESETn` | Вход | Контроллер сброса | Векторами не проверяется |
| `PADDR[11:2]` | Вход | APB | Чтение и запись регистров |
| `PCLK` | Вход | APB | Чтение и запись регистров |
| `PENABLE` | Вход | APB | Чтение и запись регистров |
| `PRDATA[7:0]` | Выход | APB | Чтение и запись регистров |
| `PSEL` | Вход | APB | Чтение и запись регистров |
| `PWDATA[7:0]` | Вход | APB | Чтение и запись регистров |
| `PWRITE` | Вход | APB | Чтение и запись регистров |
| `GPIOMIS[7:0]` | Выход | Контроллер прерываний | `GPIOITOP1` и `GPIOITOP2` |
| `GPIOINTR` | Выход | Контроллер прерываний | `GPIOITOP1` и `GPIOITOP2` |
| `nGPEN[7:0]` | Выход | Выводы | Trickbox, `GPIOITIP2`, `GPIOAFSEL` |
| `GPOUT[7:0]` | Выход | Выводы | Trickbox, `GPIOITIP1`, `GPIOAFSEL` |
| `GPIN[7:0]` | Вход | Выводы | Trickbox, `GPIODATA`, `GPIOAFSEL` |
| `nGPAFEN[7:0]` | Вход | Внутренний блок | `GPIOITIP2` |
| `GPAFOUT[7:0]` | Вход | Внутренний блок | `GPIOITIP1` |
| `GPAFIN[7:0]` | Выход | Внутренний блок | `GPIOITOP3` |

## Замечания к таблице

**Сброс.** `PRESETn` интеграционными векторами не проверяется:
его влияние проверяется отдельно на уровне системы.

**Сигналы APB.** Они проверяются обычными обращениями к регистрам:
если чтение возвращает записанное, адрес, данные и управление
соединены правильно.

**Входы с выводов.** Данные на `GPIN[7:0]` потенциально асинхронны
к `PCLK`, поэтому перед чтением через `GPIODATA` нужно подать
два передних фронта `PCLK`.

## Порядок проведения

```text
1. Проверить сигналы APB.
2. Проверить внутрикристальные входы.
3. Проверить внутрикристальные выходы.
4. Проверить первичные входы и выходы через trickbox.
5. Вернуть ITEN = 0 и сбросить накопленное состояние.
```
