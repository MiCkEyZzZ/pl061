# 3.3.3. Чувствительность GPIOIS

`GPIOIS` выбирает, по какому событию формируется прерывание:
по уровню или по фронту.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x404` |
| Тип | RW |
| Ширина | 8 бит |
| Сброс | `0x00` |

## Битовые поля

| Бит | Значение |
|-----|----------|
| 0 | Обнаружение фронта |
| 1 | Обнаружение уровня |

## Взаимодействие

| `GPIOIS` | `GPIOIBE` | `GPIOIEV` | Событие |
|----------|-----------|-----------|---------|
| 0 | 0 | 0 | Отрицательный фронт |
| 0 | 0 | 1 | Положительный фронт |
| 0 | 1 | x | Любой фронт |
| 1 | x | 0 | Низкий уровень |
| 1 | x | 1 | Высокий уровень |

## Пример

```c
/* Линия 0 — по уровню, линия 1 — по фронту */
*(volatile uint32_t *)(GPIO_BASE + 0x404) = 0x01;
```

## Замечание

После сброса выбран фронт. Если требуется уровень, бит нужно
установить явно. Изменять регистр следует при снятой маске
в `GPIOIE`, чтобы не вызвать ложное прерывание.
