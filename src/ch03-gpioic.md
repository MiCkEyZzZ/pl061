# 3.3.9. Сброс прерываний GPIOIC

`GPIOIC` сбрасывает логику обнаружения фронта для выбранных линий.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x41C` |
| Тип | WO |
| Ширина | 8 бит |
| Сброс | `0x00` |

## Битовые поля

| Бит | Действие |
|-----|----------|
| 0 | Без эффекта |
| 1 | Сбросить флаг линии |

## Правила записи

- Запись единицы сбрасывает соответствующий флаг.
- Запись нуля ничего не делает.
- Чтение не имеет смысла: регистр только для записи.

## Пример

```c
/* Сбросить все флаги */
*(volatile uint32_t *)(GPIO_BASE + 0x41C) = 0xFF;

/* Сбросить только линию 2 */
*(volatile uint32_t *)(GPIO_BASE + 0x41C) = 1u << 2;
```

## Когда нужен

Для прерываний по фронту сброс обязателен: без него детектор
не увидит следующее событие. Обычно в обработчике сбрасываются
именно те биты, которые были обработаны:

```c
uint32_t mis = *(volatile uint32_t *)(GPIO_BASE + 0x418);
/* ... обработка ... */
*(volatile uint32_t *)(GPIO_BASE + 0x41C) = mis;
```

## Для уровня

При обнаружении уровня сброс флага не поможет, если внешний
источник продолжает удерживать активный уровень. Прерывание
будет возникать повторно, пока уровень не изменится.
