# 2.2.2. Логика обнаружения прерываний

Контроллер формирует маскируемые прерывания по уровню или по
переходу на любой из восьми линий. Выход `GPIOINTR` сообщает
контроллеру прерываний, что сработала одна или несколько линий.

## Возможности

- Генерация по изменению уровня, по одному фронту или по обоим
  фронтам.
- Программируемый выбор полярности и фронта.
- Чтение сырого и маскированного статуса.
- Разрешение и запрет каждой линии отдельно.
- Сброс флагов записью.

## Регистры цепочки

| Регистр | Роль |
|---------|------|
| `GPIOIS` | Уровень или фронт |
| `GPIOIBE` | Один фронт или оба |
| `GPIOIEV` | Полярность события |
| `GPIOIE` | Маска |
| `GPIORIS` | Сырой статус |
| `GPIOMIS` | Статус после маски |
| `GPIOIC` | Сброс |

## Выходные сигналы

- **`GPIOMIS[7:0]`** — по одному сигналу на линию, после маски.
- **`GPIOINTR`** — ИЛИ всех линий `GPIOMIS`.

## Комбинация условий

| `GPIOIS` | `GPIOIBE` | `GPIOIEV` | Событие |
|----------|-----------|-----------|---------|
| 0 | 0 | 0 | Отрицательный фронт |
| 0 | 0 | 1 | Положительный фронт |
| 0 | 1 | x | Любой фронт |
| 1 | x | 0 | Низкий уровень |
| 1 | x | 1 | Высокий уровень |

`x` означает, что бит не влияет на результат.
