# Приложение A. Глоссарий

| Термин | Расшифровка | Значение |
|--------|-------------|----------|
| **AMBA** | Advanced Microcontroller Bus Architecture | Семейство шин ARM |
| **APB** | Advanced Peripheral Bus | Локальная шина для медленной периферии |
| **ATPG** | Automatic Test Pattern Generation | Автоматическая генерация тестовых последовательностей |
| **EBI** | External Bus Interface | Интерфейс внешней шины, через который подаются тестовые векторы |
| **GPIO** | General Purpose Input/Output | Ввод-вывод общего назначения |
| **ITEN** | Integration Test Enable | Бит разрешения интеграционного теста |
| **PAD** | — | Контактная площадка кристалла |
| **PrimeCell** | — | Обозначение библиотеки периферийных блоков ARM |
| **TIC** | Test Interface Controller | Ведущее устройство шины, управляющее подачей тестовых векторов |
| **Trickbox** | — | Схема шлейфа, замыкающая выходы блока на его входы |
| **Scan** | — | Метод производственного тестирования через цепочки ячеек |
| **Маска адреса** | — | Использование разрядов адреса для выбора изменяемых бит данных |
| **Активный уровень** | — | Уровень сигнала, при котором он считается asserted |
| **Фронт** | — | Переход сигнала из одного уровня в другой |
| **Уровень** | — | Устойчивое состояние сигнала |

## Обозначения регистров

| Имя | Полное название | Перевод |
|-----|-----------------|---------|
| `GPIODATA` | Data | Данные |
| `GPIODIR` | Data Direction | Направление данных |
| `GPIOIS` | Interrupt Sense | Чувствительность прерывания |
| `GPIOIBE` | Interrupt Both Edges | Прерывание по обоим фронтам |
| `GPIOIEV` | Interrupt Event | Событие прерывания |
| `GPIOIE` | Interrupt Mask | Маска прерывания |
| `GPIORIS` | Raw Interrupt Status | Сырой статус прерывания |
| `GPIOMIS` | Masked Interrupt Status | Маскированный статус прерывания |
| `GPIOIC` | Interrupt Clear | Сброс прерывания |
| `GPIOAFSEL` | Mode Control Select | Выбор режима управления |
| `GPIOITCR` | Integration Test Control | Управление интеграционным тестом |
| `GPIOITIP1/2` | Integration Test Input | Тестовый вход |
| `GPIOITOP1/2/3` | Integration Test Output | Тестовый выход |

## Обозначения сигналов

| Сигнал | Значение |
|--------|----------|
| `nGPEN` | Разрешение выхода, активный низким |
| `GPOUT` | Данные на выход |
| `GPIN` | Данные со входа |
| `nGPAFEN` | Разрешение аппаратного управления, активный низким |
| `GPAFOUT` | Данные аппаратного управления на выход |
| `GPAFIN` | Данные аппаратного управления со входа |
| `GPIOINTR` | Объединённое прерывание |
| `PRESETn` | Сброс шины, активный низким |
