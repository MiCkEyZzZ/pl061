# 3.3.2. Направление данных GPIODIR

`GPIODIR` задаёт направление каждой линии в программном режиме.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x400` |
| Тип | RW |
| Ширина | 8 бит |
| Сброс | `0x00` |

## Битовые поля

| Бит | Значение |
|-----|----------|
| 0 | Линия — вход |
| 1 | Линия — выход |

## Свойства

- После сброса все линии — входы.
- Бит действует только при `GPIOAFSEL[n] = 0`.
- Изменение направления не меняет значение в `GPIODATA`.

## Пример

```c
#define GPIO_DIR    (GPIO_BASE + 0x400)

/* 0–3 выходы, 4–7 входы */
*(volatile uint32_t *)GPIO_DIR = 0x0F;
```

## Замечание о переключении

При переводе линии из выхода во вход выходной драйвер отключается,
и вывод переходит в высокоимпедансное состояние. Если к линии
подключена нагрузка, это может быть воспринято как изменение
уровня. При необходимости внешнюю подтяжку следует предусмотреть
на уровне схемы.
