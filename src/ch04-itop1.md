# 4.3.4. GPIOITOP1

`GPIOITOP1` — регистр установки внутрикристального выхода
`GPIOMIS[7:0]`.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x60C` |
| Тип | WO |
| Ширина | 8 бит |
| Сброс | `0x00` |

## Битовые поля

| Биты | Имя | Описание |
|------|-----|----------|
| 7:0 | `GPIOMIS` | Значение, выдаваемое на внутрикристальный выход |

## Только запись

Регистр не читается. Чтобы узнать, что было записано, нужно
установить `ITEN = 1` и прочитать `GPIOMIS` — в тестовом режиме
этот регистр отражает содержимое `GPIOITOP1`.

## Зачем нужен

`GPIOMIS[7:0]` в рабочем режиме формируется логикой прерываний.
В тестовом режиме источником становится `GPIOITOP1`, что позволяет
проверить проводку от контроллера до контроллера прерываний.

## Пример

```c
#define GPIO_ITOP1  (GPIO_BASE + 0x60C)
#define GPIO_MIS    (GPIO_BASE + 0x418)

*(volatile uint32_t *)(GPIO_BASE + 0x600) = 1;  /* ITEN = 1 */

/* Подать шаблон на выходы прерываний */
*(volatile uint32_t *)GPIO_ITOP1 = 0xA5;

/* Прочитать через GPIOMIS */
uint32_t back = *(volatile uint32_t *)GPIO_MIS & 0xFF;
```

## Сброс

После сброса регистр равен `0x00`, то есть на выходы подаются
нули.

## Замечание

`GPIOINTR` формируется как ИЛИ по битам `GPIOMIS`. Поэтому запись
ненулевого значения в `GPIOITOP1` должна приводить к высокому
уровню на `GPIOINTR`, что можно проверить через `GPIOITOP2`.
