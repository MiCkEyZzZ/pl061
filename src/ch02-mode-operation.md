# 2.3.5. Управление режимом

Линиями можно управлять через аппаратный интерфейс. Режим каждой
линии выбирается регистром `GPIOAFSEL`.

## Что происходит при аппаратном режиме

Когда для линии включено аппаратное управление, сигналы данных
и направления от регистров игнорируются. Передача данных и
управления по этой линии выполняется внешним вспомогательным блоком.

## Таблица конфигурации выводов

| Параметр | Аппаратный режим | Программный режим |
|----------|------------------|-------------------|
| `GPIOAFSEL` | 1 | 0 |
| Направление | `nGPAFEN` | `GPIODIR` |
| Выходные данные | `GPAFOUT` | `GPIODATA` |
| Входные данные | `GPIN` → `GPAFIN` | `GPIN` → `GPIODATA` |
| Разрешение вывода | `nGPEN` | `nGPEN` от `GPIODIR` |

## Аппаратный режим

Линии `XP[7:4]` в примере документации настроены на аппаратное
управление.

- **Выходы** (`nGPAFEN = 0`): данные берутся из `GPAFOUT[7:6]`
  и выдаются на выводы, а также возвращаются на `GPAFIN[7:6]`.
- **Входы** (`nGPAFEN = 1`): данные с выводов передаются
  на `GPAFIN[5:4]`.

Во всех случаях значения доступны для чтения через `GPIODATA`.

## Программный режим

Линии `XP[3:0]` настроены на программное управление.

- **Выходы** (`GPIODIR = 1`): данные берутся из `GPIODATA[3:2]`.
- **Входы** (`GPIODIR = 0`): данные с выводов читаются через
  `GPIODATA[1:0]`, но не выдаются на `GPAFIN`.

Сигналы `GPAFIN` в программном режиме принудительно удерживаются
на низком уровне для экономии энергии.

## Экономия энергии

Отключение пути к `GPAFIN` в программном режиме снижает
переключения на внутренних линиях, когда аппаратное управление
не используется.
