# 4.3.2. GPIOITIP1

`GPIOITIP1` — регистр чтения и установки внутрикристального входа
`GPAFOUT[7:0]`.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x604` |
| Тип | RW |
| Ширина | 8 бит |
| Сброс | `0x00` |

## Битовые поля

| Биты | Имя | Описание |
|------|-----|----------|
| 7:0 | `GPAFOUT` | Значение, подаваемое на внутрикристальный вход |

## Запись

Запись задаёт значение, которое в тестовом режиме выдаётся
на внутрикристальный вход `GPAFOUT[7:0]` вместо сигнала
от внешнего блока.

## Чтение

Чтение возвращает значение `GPAFOUT[7:0]` на выходе тестового
мультиплексора. При `ITEN = 0` это значение приходит извне,
при `ITEN = 1` — из самого регистра.

## Пример самопроверки

```c
#define GPIO_ITIP1  (GPIO_BASE + 0x604)

*(volatile uint32_t *)(GPIO_BASE + 0x600) = 1;  /* ITEN = 1 */

for (int bit = 0; bit < 8; bit++) {
    uint32_t pattern = 1u << bit;

    *(volatile uint32_t *)GPIO_ITIP1 = pattern;
    if ((*(volatile uint32_t *)GPIO_ITIP1 & 0xFF) != pattern)
        /* ошибка соединения или логики */
        ;
}
```

Проверка «записать 1, затем 0 и прочитать» обнаруживает залипание
линий и обрывы.

## Применение в системе

Если контроллер уже встроен в систему, при `ITEN = 0` чтение
`GPIOITIP1` показывает значение, которое внешний блок подаёт
на `GPAFOUT`. Это позволяет проверить соединение с этим блоком,
не выводя сигнал на контактные площадки.
