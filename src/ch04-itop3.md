# 4.3.6. GPIOITOP3

`GPIOITOP3` — регистр чтения и установки внутрикристального выхода
`GPAFIN[7:0]`.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x614` |
| Тип | RW |
| Ширина | 8 бит |
| Сброс | `0x00` |

## Битовые поля

| Биты | Имя | Описание |
|------|-----|----------|
| 7:0 | `GPAFIN` | Значение, выдаваемое на внутрикристальный выход |

## Запись

Запись задаёт значение, которое в тестовом режиме выдаётся
на `GPAFIN[7:0]` вместо данных от рабочей логики.

## Чтение

Чтение возвращает значение `GPAFIN[7:0]` на выходе тестового
мультиплексора. При `ITEN = 0` это то, что контроллер реально
выдаёт внешнему блоку, при `ITEN = 1` — содержимое регистра.

## Пример

```c
#define GPIO_ITOP3  (GPIO_BASE + 0x614)

*(volatile uint32_t *)(GPIO_BASE + 0x600) = 1;  /* ITEN = 1 */

*(volatile uint32_t *)GPIO_ITOP3 = 0x55;
if ((*(volatile uint32_t *)GPIO_ITOP3 & 0xFF) != 0x55)
    /* несоответствие: проверить соединение */
    ;

*(volatile uint32_t *)GPIO_ITOP3 = 0xAA;
if ((*(volatile uint32_t *)GPIO_ITOP3 & 0xFF) != 0xAA)
    /* несоответствие */
    ;
```

Шаблоны `0x55` и `0xAA` проверяют все восемь линий в обоих
состояниях.

## Применение в системе

При `ITEN = 0` чтение `GPIOITOP3` показывает, что контроллер
выдаёт на `GPAFIN`, то есть проверяет связь с потребителем этого
сигнала — без вмешательства в работу линий.
