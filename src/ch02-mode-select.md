# 2.1.4. Регистр выбора режима

`GPIOAFSEL` — регистр выбора режима управления линией.

## Значение битов

| Бит | Режим |
|-----|-------|
| 0 | Программный: линия управляется через APB |
| 1 | Аппаратный: линия управляется внешним блоком |

## Что меняется

| Параметр | Программный режим | Аппаратный режим |
|----------|-------------------|------------------|
| Направление | `GPIODIR` | `nGPAFEN` |
| Выходные данные | `GPIODATA` | `GPAFOUT` |
| Входные данные | `GPIN` → `GPIODATA` | `GPIN` → `GPAFOUT`/`GPAFIN` |
| Чтение через APB | Да | Да, состояние линии доступно |

## Свойства

- После сброса все биты равны нулю: все линии программные.
- Переключение можно делать для каждой линии отдельно.
- В аппаратном режиме регистры `GPIODIR` и `GPIODATA` для этой линии
  не действуют, но чтение `GPIODATA` по-прежнему возвращает уровень
  на выводе.

## Пример

```c
/* Линии 7 и 6 — аппаратное управление, остальные — программное */
*(volatile uint32_t *)(GPIO_BASE + 0x420) = 0xC0;
```

## Типичное применение

Аппаратный режим используется, когда линией должен управлять
специализированный блок (например, контроллер другого интерфейса),
а процессор лишь изредка читает её состояние.
