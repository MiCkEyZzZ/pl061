# 3.3.8. Маскированный статус GPIOMIS

`GPIOMIS` содержит состояние прерываний после применения маски.
Именно эти значения выдаются на индивидуальные линии и участвуют
в формировании `GPIOINTR`.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x418` |
| Тип | RO |
| Ширина | 8 бит |
| Сброс | `0x00` |

## Битовые поля

| Бит | Значение |
|-----|----------|
| 0 | Линия не выдаёт прерывание |
| 1 | Линия выдаёт прерывание |

## Вычисление

```text
GPIOMIS = GPIORIS AND GPIOIE
```

Бит установлен, только если событие произошло и прерывание
разрешено.

## Выходы

| Выход | Источник |
|-------|----------|
| `GPIOMIS[n]` | Одноимённый бит |
| `GPIOINTR` | ИЛИ всех бит `GPIOMIS` |

## Пример обработчика

```c
void gpio_irq(void)
{
    uint32_t mis = *(volatile uint32_t *)(GPIO_BASE + 0x418);

    if (mis & (1u << 0)) {
        /* обработка линии 0 */
    }
    if (mis & (1u << 3)) {
        /* обработка линии 3 */
    }

    /* Сбросить обработанные фронты */
    *(volatile uint32_t *)(GPIO_BASE + 0x41C) = mis;
}
```

## Замечание

Для прерываний по уровню сброс через `GPIOIC` не устранит причину:
если линия остаётся активной, прерывание возникнет снова. В этом
случае нужно воздействовать на внешний источник.
