# 2.1.1. Регистр направления данных

`GPIODIR` — восьмибитный регистр, задающий направление каждой линии.

## Значение битов

| Бит | Направление |
|-----|-------------|
| 0 | Вход |
| 1 | Выход |

## Свойства

- Каждый бит действует независимо: в одном порту могут быть
  одновременно входы и выходы.
- После сброса все биты равны нулю, то есть все линии работают
  как входы.
- В программном режиме регистр полностью определяет направление.
- В аппаратном режиме (при `GPIOAFSEL = 1` для данной линии)
  направление задаётся внешними сигналами `nGPAFEN`, а бит `GPIODIR`
  игнорируется.

## Пример

```c
/* Линии 0–3 — выходы, 4–7 — входы */
*(volatile uint32_t *)(GPIO_BASE + 0x400) = 0x0F;
```

## Замечание

Перед изменением направления линии с выхода на вход стоит учесть
внешнюю схему: если на выводе остаётся активный сигнал, переход
в высокоимпедансное состояние может быть воспринят подключённым
устройством как изменение уровня.
