# 3.3.1. Регистр данных GPIODATA

`GPIODATA` — регистр данных. В программном режиме записанные
значения выдаются на выводы, настроенные как выходы.

## Расположение

| Параметр | Значение |
|----------|----------|
| Диапазон | `0x000`–`0x3FC` |
| Тип | RW |
| Ширина | 8 бит |
| Сброс | `0x00` |

## Маска адреса

Запись возможна только в те биты, для которых соответствующий бит
`PADDR[9:2]` равен 1. Остальные биты не изменяются.

При чтении биты, у которых маска равна 1, возвращаются; остальные
читаются как 0.

| Адрес | `PADDR[9:2]` | Доступные биты |
|-------|--------------|----------------|
| `+0x004` | `0b0000000001` | 0 |
| `+0x008` | `0b0000000010` | 1 |
| `+0x098` | `0b0000100110` | 5, 2, 1 |
| `+0x0C4` | `0b0000110001` | 5, 4, 0 |
| `+0x3FC` | `0b1111111111` | все |

## Битовые поля

| Биты | Имя | Описание |
|------|-----|----------|
| 7:0 | `DATA` | Входные или выходные данные |

## Чтение

- Для выхода возвращается последнее записанное значение.
- Для входа возвращается текущий уровень на выводе.

## Пример

```c
#define GPIO_DATA   (GPIO_BASE + 0x000)

/* Установить только бит 3, не трогая остальные:
   адрес +0x00C даёт маску с битом 3 */
*(volatile uint32_t *)(GPIO_BASE + 0x00C) = 1u << 3;

/* Прочитать все линии */
uint32_t all = *(volatile uint32_t *)(GPIO_BASE + 0x3FC);
```

## Замечание

Запись по адресу с маской не требует чтения-модификации-записи.
Это делает операцию атомарной по отношению к другим драйверам,
работающим с соседними битами.
