# 2.2. Функциональное описание

Функционально контроллер состоит из трёх частей:

| Часть | Раздел |
|-------|--------|
| Интерфейс AMBA APB | 2.2.1 |
| Логика обнаружения прерываний | 2.2.2 |
| Управление режимом | 2.2.3 |

## Блок-схема

```text
        APB
         │
   ┌─────▼──────────────────────────────┐
   │        Интерфейс APB               │
   │  (регистры, декодирование адреса)  │
   └──┬──────────────┬──────────────┬───┘
      │              │              │
      ▼              ▼              ▼
 ┌─────────┐   ┌───────────┐  ┌──────────┐
 │GPIODIR  │   │Прерывания │  │GPIOAFSEL │
 │GPIODATA │   │ 7 рег.    │  │          │
 └────┬────┘   └─────┬─────┘  └────┬─────┘
      │              │             │
      ▼              ▼             ▼
 ┌──────────────────────────────────────┐
 │     Мультиплексор режимов            │
 └──────────────┬───────────────────────┘
                │
                ▼
          выводы GPIO[7:0]
```

## Тестовая логика

На схеме не показана тестовая логика. Она описана отдельно
в главе 4 и не участвует в обычной работе контроллера.

## Взаимодействие частей

- Интерфейс APB принимает обращения и обновляет регистры.
- Логика прерываний следит за линиями и вырабатывает `GPIOINTR`.
- Управление режимом выбирает источник сигналов для каждой линии:
  регистры или аппаратный интерфейс.
