# 3.3.10. Выбор режима GPIOAFSEL

`GPIOAFSEL` выбирает для каждой линии программное или аппаратное
управление.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x420` |
| Тип | RW |
| Ширина | 8 бит |
| Сброс | `0x00` |

## Битовые поля

| Бит | Режим |
|-----|-------|
| 0 | Программный |
| 1 | Аппаратный |

## Что переключается

| Сигнал | Программный | Аппаратный |
|--------|-------------|------------|
| Направление | `GPIODIR` | `nGPAFEN` |
| Выход | `GPIODATA` | `GPAFOUT` |
| Вход | `GPIN` → `GPIODATA` | `GPIN` → `GPAFIN` |

## Пример

```c
/* Линии 7:4 — аппаратные, 3:0 — программные */
*(volatile uint32_t *)(GPIO_BASE + 0x420) = 0xF0;
```

## Замечание

В аппаратном режиме состояние линии всё равно можно прочитать
через `GPIODATA`. Это удобно для контроля, но не даёт управлять
линией из программы.

Неиспользуемые входы `nGPAFEN` должны быть привязаны к высокому
уровню, иначе поведение линии окажется неопределённым.
