# 1.1. О контроллере GPIO (PL061)

PL061 — контроллер ввода-вывода общего назначения семейства
ARM PrimeCell. Он даёт программному обеспечению восемь
независимых линий, каждая из которых может быть входом или
выходом.

## Состав блока

| Часть | Назначение |
|-------|------------|
| Интерфейс AMBA APB | Доступ к регистрам со стороны шины |
| Регистр данных | Чтение состояния входов и запись значений выходов |
| Регистр направления | Определяет, какие линии работают на вход, а какие на выход |
| Блок прерываний | Обнаружение уровня или фронта, маскирование, объединение |
| Блок выбора режима | Переключение линии между программным и аппаратным управлением |
| Регистры идентификации | Постоянные значения для распознавания компонента |

## Подключение

Контроллер занимает 4 КБ адресного пространства и подключается
к шине APB как ведомое устройство. Восемь линий `GPIO[7:0]`
выводятся на контактные площадки кристалла через двунаправленные
буферы.

```text
        AMBA APB
           │
           ▼
   ┌───────────────┐
   │     PL061     │
   │               │──── GPIOINTR ──▶ контроллер прерываний
   │               │──── GPIO[7:0] ──▶ выводы
   └───────────────┘
```

## Основные сценарии

- **Программный режим.** Процессор задаёт направление через
  `GPIODIR`, пишет значения в `GPIODATA` и читает состояние линий
  оттуда же.
- **Прерывания.** Линия настраивается на срабатывание по уровню
  или фронту; контроллер выставляет общий выход `GPIOINTR`.
- **Аппаратный режим.** Управление линией передаётся внешнему блоку
  через `GPIOAFSEL`; регистры данных при этом игнорируются.

## Применение

PL061 типично используется для:

- кнопок и переключателей;
- светодиодов и исполнительных устройств;
- сигналов сброса и готовности периферии;
- прерываний от внешних микросхем;
- служебных линий, управляемых программно.

## Ограничения

- Всего восемь линий; расширение выполняется несколькими
  экземплярами контроллера.
- Нет встроенной синхронизации входов: при работе от асинхронного
  источника нужно учитывать дребезг и метастабильность на уровне
  системы.
- Электрические параметры (ток, подтяжка, защита) определяются
  интеграцией, а не самим блоком.
