# 2.1. Обзор контроллера GPIO

PL061 — ведомое устройство шины AMBA APB. Он предоставляет восемь
программируемых линий, которыми можно управлять двумя способами:

- **программно** — через регистры на шине APB;
- **аппаратно** — через интерфейс аппаратного управления.

## Состав регистров

| Группа | Регистры |
|--------|----------|
| Направление данных | `GPIODIR` |
| Данные | `GPIODATA` |
| Управление прерываниями | `GPIOIS`, `GPIOIBE`, `GPIOIEV`, `GPIOIE`, `GPIORIS`, `GPIOMIS`, `GPIOIC` |
| Выбор режима | `GPIOAFSEL` |
| Идентификация | `GPIOPeriphID0-3`, `GPIOPCellID0-3` |

## Структура

```text
                 ┌──────────────────────────┐
   AMBA APB ────▶│  Регистры и управление   │
                 │                          │
                 │  GPIODIR   GPIODATA      │
                 │  Блок прерываний         │──▶ GPIOINTR
                 │  GPIOAFSEL               │
                 └───────┬──────────▲───────┘
                         │          │
                 аппаратный    программный
                  интерфейс      тракт
                         │          │
                         ▼          ▼
                   ┌──────────────────┐
                   │  Выводы GPIO[7:0]│
                   └──────────────────┘
```

## Что видит процессор

Через APB доступны данные, управление и состояние. Каждая линия
имеет свой бит во всех восьмибитных регистрах. Направление задаётся
независимо для каждой линии, прерывания настраиваются и маскируются
тоже независимо.

## Масштабирование

Ширина порта — восемь линий. Порт большей ширины (16, 24, 32 бита
и более) получается объединением нескольких экземпляров контроллера.
При этом каждый экземпляр сохраняет собственную карту регистров.
