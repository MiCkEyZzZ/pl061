# 3.3.5. Событие GPIOIEV

`GPIOIEV` задаёт полярность события: какой фронт или уровень
считается активным.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x40C` |
| Тип | RW |
| Ширина | 8 бит |
| Сброс | `0x00` |

## Битовые поля

| Бит | При фронте (`GPIOIS = 0`) | При уровне (`GPIOIS = 1`) |
|-----|---------------------------|---------------------------|
| 0 | Отрицательный фронт | Низкий уровень |
| 1 | Положительный фронт | Высокий уровень |

## Пример

```c
/* Линия 2: положительный фронт / высокий уровень */
*(volatile uint32_t *)(GPIO_BASE + 0x40C) = 1u << 2;
```

## Взаимодействие с GPIOIBE

Если для линии установлен бит в `GPIOIBE`, выбор фронта в `GPIOIEV`
игнорируется: линия реагирует на оба фронта. Для уровня `GPIOIBE`
не действует.

## Замечание

Настройку следует выполнять при снятой маске в `GPIOIE`. Иначе
изменение полярности может быть воспринято как событие и вызвать
прерывание.
