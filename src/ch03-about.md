# 3.1. Общие сведения

Базовый адрес контроллера не фиксирован: он назначается при
интеграции. Смещения регистров относительно базового адреса
постоянны.

## Правила доступа

- Все обращения — 32-битные, выровненные по границе слова.
- Адрес регистра: `адрес = base + offset`.
- Регистры `RO` только читаются, запись игнорируется.
- Регистры `WO` только пишутся, чтение не имеет смысла.
- Зарезервированные биты при записи должны сохранять значение.
- Значащие биты занимают младший байт слова.

## Область адресов

Контроллер занимает 4 КБ.

| Диапазон | Назначение |
|----------|------------|
| `0x000`–`0x3FC` | `GPIODATA`, 256 адресов с маской |
| `0x400`–`0x420` | Регистры управления |
| `0x424`–`0xFCC` | Резерв для будущих функций и теста |
| `0xFD0`–`0xFDC` | Резерв для расширения идентификации |
| `0xFE0`–`0xFEC` | `GPIOPeriphID0-3` |
| `0xFF0`–`0xFFC` | `GPIOPCellID0-3` |

## Особенность GPIODATA

`GPIODATA` — не обычный регистр. Младшие биты адреса `PADDR[9:2]`
работают как маска: они определяют, какие биты участвуют
в операции. Поэтому одно и то же значение, записанное по разным
адресам, даёт разный результат.

## Соглашение об именах

| Суффикс | Значение |
|---------|----------|
| `DATA` | Data — данные |
| `DIR` | Direction — направление |
| `IS` | Interrupt Sense — чувствительность |
| `IBE` | Interrupt Both Edges — оба фронта |
| `IEV` | Interrupt Event — событие |
| `IE` | Interrupt Enable — разрешение |
| `RIS` | Raw Interrupt Status — сырой статус |
| `MIS` | Masked Interrupt Status — маскированный статус |
| `IC` | Interrupt Clear — сброс |
| `AFSEL` | Alternate Function Select — выбор режима |
