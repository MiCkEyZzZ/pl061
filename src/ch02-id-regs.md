# 2.1.5. Регистры идентификации

Два набора регистров позволяют программно убедиться, что по данному
адресу находится именно PL061.

## Идентификатор периферии

| Регистр | Смещение | Значение |
|---------|----------|----------|
| `GPIOPeriphID0` | `0xFE0` | `0x61` |
| `GPIOPeriphID1` | `0xFE4` | `0x10` |
| `GPIOPeriphID2` | `0xFE8` | `0x04` |
| `GPIOPeriphID3` | `0xFEC` | `0x00` |

Составное слово: `0x00041061`.

## Идентификатор PrimeCell

| Регистр | Смещение | Значение |
|---------|----------|----------|
| `GPIOPCellID0` | `0xFF0` | `0x0D` |
| `GPIOPCellID1` | `0xFF4` | `0xF0` |
| `GPIOPCellID2` | `0xFF8` | `0x05` |
| `GPIOPCellID3` | `0xFFC` | `0xB1` |

Составное слово: `0xB105F00D`.

## Зачем нужны два набора

`GPIOPCellID` указывает на семейство PrimeCell, а `GPIOPeriphID` —
на конкретный компонент. Совместная проверка отсекает и периферию
других семейств, и другие компоненты PrimeCell.

## Замечание

Регистры только для чтения, значения заданы в кремнии. Обращения
должны быть 32-битными; значащие байты маскируются.
