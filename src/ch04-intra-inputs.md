# 4.4.1. Внутрикристальные входы

К внутрикристальным входам относятся `nGPAFEN[7:0]` и `GPAFOUT[7:0]`.
Они приходят от других блоков системы, а не с контактных площадок.

## Как устроена обвязка

В пути чтения этих сигналов стоит мультиплексор, управляемый
битом `ITEN`:

| `ITEN` | Источник `nGPAFEN` | Источник `GPAFOUT` |
|--------|--------------------|--------------------|
| 0 | внешние входы `nGPAFEN` | внешние входы `GPAFOUT` |
| 1 | `GPIOITIP2[7:0]` | `GPIOITIP1[7:0]` |

То есть при `ITEN = 1` сигналы берутся из тестовых регистров.

## Автономная проверка

Когда контроллер испытывается отдельно от системы:

1. Записать `1` в бит `ITEN` регистра `GPIOITCR`. Это включает
   путь от `GPIOITIP1` к `GPAFOUT` и от `GPIOITIP2` к `nGPAFEN`.
2. Записать `1`, затем `0` в каждый бит `GPIOITIP1[7:0]`
   и `GPIOITIP2[7:0]`.
3. Прочитать те же биты и убедиться, что записанное значение
   читается обратно.

```c
static void test_intra_inputs(void)
{
    *(volatile uint32_t *)(GPIO_BASE + 0x600) = 1;   /* ITEN */

    for (int bit = 0; bit < 8; bit++) {
        uint32_t p = 1u << bit;

        *(volatile uint32_t *)(GPIO_BASE + 0x604) = p;
        if ((*(volatile uint32_t *)(GPIO_BASE + 0x604) & 0xFF) != p)
            report_error(1, bit);

        *(volatile uint32_t *)(GPIO_BASE + 0x604) = 0;
        if ((*(volatile uint32_t *)(GPIO_BASE + 0x604) & 0xFF) != 0)
            report_error(1, bit);

        *(volatile uint32_t *)(GPIO_BASE + 0x608) = p;
        if ((*(volatile uint32_t *)(GPIO_BASE + 0x608) & 0xFF) != p)
            report_error(2, bit);
    }
}
```

## Проверка в составе системы

Когда контроллер уже встроен:

1. Записать `0` в `ITEN`. Это включает нормальный путь: от внешних
   выводов `nGPAFEN` к внутренним сигналам `nGPAFEN` и от внешних
   `GPAFOUT` к внутренним `GPAFOUT`.
2. Устройством, подключённым к линиям аппаратного управления,
   переключить `nGPAFEN[7:0]` и `GPAFOUT[7:0]` из `1` в `0`.
3. Прочитать `GPIOITIP2[7:0]` и `GPIOITIP1[7:0]` и убедиться,
   что значения от внешнего устройства доходят до контроллера.

## Что это выявляет

- Обрыв или замыкание линии между блоками.
- Неправильную разводку отдельного бита.
- Отсутствие сигнала от неактивного соседнего блока.
