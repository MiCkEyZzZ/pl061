# 3.3.7. Сырой статус GPIORIS

`GPIORIS` показывает состояние условий прерывания до применения
маски.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x414` |
| Тип | RO |
| Ширина | 8 бит |
| Сброс | `0x00` |

## Битовые поля

| Бит | Значение |
|-----|----------|
| 0 | Условие прерывания линии не выполнено |
| 1 | Условие прерывания линии выполнено |

## Что означает

Бит устанавливается, когда линия удовлетворила всем требованиям
детектора (`GPIOIS`, `GPIOIBE`, `GPIOIEV`), ещё до проверки маски
`GPIOIE`. Поэтому событие видно в `GPIORIS` даже при запрещённом
прерывании.

## Связь с GPIOMIS

```text
GPIOMIS = GPIORIS AND GPIOIE
```

## Сброс

Регистр только для чтения. Флаги снимаются записью единицы
в соответствующий бит `GPIOIC` либо общим сбросом.

## Применение

- Опрос событий без разрешения прерываний.
- Диагностика: видно, что линия срабатывала, даже если прерывание
  было замаскировано.
- Проверка настройки детектора до включения `GPIOIE`.

```c
uint32_t raw = *(volatile uint32_t *)(GPIO_BASE + 0x414);
if (raw & 1u)
    /* линия 0 фиксировала событие */
```
