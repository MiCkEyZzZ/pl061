# 2.2.1. Интерфейс AMBA APB

AMBA APB — локальная вторичная шина, которая обеспечивает
малопотребляющее расширение более быстрой шины AHB. APB объединяет
периферийные устройства с узкой шиной, чтобы не загружать системную
шину, и предоставляет доступ к регистрам через адресное пространство.

## Что делает интерфейс

- Формирует сигналы чтения и записи для регистров управления,
  прерываний и данных.
- Формирует отдельное декодирование только для чтения — для доступа
  к регистрам идентификации.
- Содержит элементы хранения для регистров данных, направления,
  выбора режима, прерываний и идентификации.

## Особенности

| Свойство | Значение |
|----------|----------|
| Роль | Ведомое устройство APB |
| Область адресов | 4 КБ |
| Разрядность данных | 8 значащих бит |
| Доступ | 32-битные обращения |

## Следствия для программирования

- Регистры расположены в 32-битных словах, но используют младший
  байт.
- Регистр данных занимает 256 слов: маска адреса формируется внутри
  интерфейса.
- Обращения к регистрам идентификации должны быть 32-битными
  (`LDR`/`STR`), даже если значение 8-битное.

## Почему APB

APB требует меньше сигналов и потребляет меньше энергии, чем AHB,
поэтому хорошо подходит для медленной периферии. Платой является
более низкая пропускная способность, что для GPIO не критично.
