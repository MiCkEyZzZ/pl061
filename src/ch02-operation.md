# 2.3. Работа контроллера

В этом разделе описано поведение контроллера после сброса,
при конфигурировании, при работе линий, прерываний и выборе режима.

## Порядок изложения

| Раздел | Тема |
|--------|------|
| 2.3.1 | Сброс интерфейса |
| 2.3.2 | Конфигурирование интерфейса |
| 2.3.3 | Работа линий ввода-вывода |
| 2.3.4 | Работа прерываний |
| 2.3.5 | Управление режимом |

## Типичная последовательность запуска

```text
1. Снять сброс.
2. Настроить направление линий (GPIODIR).
3. При необходимости настроить прерывания:
   GPIOIS → GPIOIBE → GPIOIEV → три такта → GPIOIC = 0xFF → GPIOIE.
4. Записать начальные значения выходов (GPIODATA).
5. Включить нужные линии в GPIOAFSEL, если требуется аппаратный режим.
```
