# 3.3.6. Маска прерываний GPIOIE

`GPIOIE` разрешает или запрещает прерывание от каждой линии.

## Расположение

| Параметр | Значение |
|----------|----------|
| Смещение | `0x410` |
| Тип | RW |
| Ширина | 8 бит |
| Сброс | `0x00` |

## Битовые поля

| Бит | Значение |
|-----|----------|
| 0 | Прерывание линии запрещено |
| 1 | Прерывание линии разрешено |

## Влияние

Установленный бит разрешает линии формировать:

- индивидуальный сигнал в `GPIOMIS[n]`;
- вклад в общий выход `GPIOINTR`.

Снятый бит блокирует оба выхода, но не мешает `GPIORIS` фиксировать
событие.

## Пример

```c
/* Разрешить прерывания от линий 0 и 3 */
*(volatile uint32_t *)(GPIO_BASE + 0x410) = (1u << 0) | (1u << 3);
```

## Порядок включения

Разрешение следует выполнять последним шагом настройки:

```text
GPIOIS → GPIOIBE → GPIOIEV → выдержка → GPIOIC = 0xFF → GPIOIE
```

Так исключаются прерывания по событиям, накопленным во время
конфигурирования.

## После сброса

Все биты равны нулю: прерывания запрещены. Это безопасное
исходное состояние.
