# Аудитория и соглашения

## Для кого

Руководство рассчитано на:

- разработчиков драйверов, которым нужен доступ к линиям GPIO
  и их прерываниям;
- инженеров, интегрирующих PL061 в систему на кристалле;
- специалистов по верификации, использующих тестовые регистры.

Предполагается знакомство с шиной AMBA APB, понятиями регистра,
маски прерывания и активного уровня сигнала.

## Соглашения

| Обозначение | Значение |
|-------------|----------|
| `RW` | Регистр доступен для чтения и записи |
| `RO` | Только для чтения |
| `WO` | Только для записи |
| `—` | Поле зарезервировано |
| `x` | Значение не имеет смысла |
| `0x` | Шестнадцатеричная запись |
| `0b` | Двоичная запись |

## Активные уровни

- Сигналы AMBA APB активны высоким уровнем.
- Прерывания `GPIOINTR` и индивидуальные выходы активны высоким
  уровнем.
- Сигналы разрешения выводов `nGPEN` и `nGPAFEN` активны низким
  уровнем.

## Запись регистров

Все регистры расположены в 32-битных словах, но занимают младшие
8 бит. Обращения должны быть 32-битными и выровненными по границе
слова. Запись в зарезервированные биты не влияет на работу, чтение
из них не определено.

## Адресация данных

Регистр данных занимает не одно слово, а 256 последовательных
адресов. Младшие биты адреса `PADDR[9:2]` работают как маска:
они определяют, какие биты данных участвуют в операции. Это
ключевая особенность PL061, и ей посвящён отдельный раздел.
