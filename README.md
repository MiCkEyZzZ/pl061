# ARM PrimeCell GPIO (PL061)

Русскоязычное техническое руководство по контроллеру ввода-вывода
общего назначения ARM PrimeCell PL061, составленное по структуре
официального документа ARM **DDI 0190B**.

## Сборка

```console
$ mdbook build      # результат в ./book
$ mdbook serve      # предпросмотр на http://localhost:3000
```

## Структура

| Глава | Содержание |
|-------|------------|
| Предисловие | Назначение, аудитория, соглашения, литература |
| 1 | Общее описание и возможности |
| 2 | Функциональное описание |
| 3 | Модель программиста: карта регистров |
| 4 | Модель программиста для тестирования |
| 5 | Описание сигналов |
| Приложение A | Глоссарий |

## Базовые сведения

| Параметр | Значение |
|----------|----------|
| Семейство | ARM PrimeCell |
| Шина | AMBA APB, ведомое устройство |
| Число линий | 8 |
| Разрядность регистров | 8 бит в 32-битных словах |
| Область адресов | 4 КБ |

Текст написан самостоятельно и описывает технические факты устройства.
Документ ARM DDI 0190B принадлежит ARM Limited; его дословный перевод
здесь не приводится.
